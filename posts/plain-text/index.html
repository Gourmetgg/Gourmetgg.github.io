plain text, a small luxury

files that ask very little of the future

17 March 20261 min read[ technology, writing ]

A text file makes very few demands. It does not need an account. It does not ask which workspace you belong to. It can be opened by a surprising number of programs, including ones that have not been written yet.

This is a useful quality for things you want to keep.

boring is a feature

My favorite notes are not especially sophisticated. A title, a date, a few paragraphs. Sometimes a link. There are no elaborate properties to maintain, no system to administer before I can begin a sentence.

A file called reading-notes.txt is not a perfect knowledge base. It is, however, a place where I can put a thought and find it again.

The simplicity has a cost. Plain text will not do every job. It cannot replace every spreadsheet or every carefully laid out document. But for a surprising number of notes, it does enough.

an ordinary kind of permanence

Nothing digital is permanent by default. Files still need backups. Formats still have conventions. Yet there is something reassuring about being able to read the contents without the original application.

I do not need my notebook to be clever. I need it to be there when I return.
